下面是一组基于需求文档生成的 Via App 从头到尾 UX Flow。我会按 新用户首次使用 → 7 天初始化 → 老用户每日使用 → 周/月/季/年总结 → 历史与设置 → 异常状态 来组织。需求文档中明确 Via 是一款“私密、简单、温和的 AI 日记 App”，核心是每天 5 个问题、连续 7 天后生成第一份 AI 一周观察报告，并长期提供周/月/季度/年度复盘。

# Via App UX Flow 总览

## 0. 产品体验基调

Via 不是效率 App，也不是目标管理工具，而是一个 私密日记风格的个人复盘教练。

整体 UX 应避免：

- 强打卡感
    
- KPI 仪表盘感
    
- 排行榜、社交压力
    
- 过度数据化
    
- 过度励志鸡汤
    

整体应强调：

- 安静
    
- 私密
    
- 温柔
    
- 低负担
    
- 日记感
    
- 少信息密度
    
- 每天 3–5 分钟即可完成

# 3. 7 天初始化 Flow

## 3.1 Day 2–6 首页状态

顶部仍然是日期和今日入口，但增加初始化进度。

示例：

## 3.3 First Weekly Observation Report / 第一份一周观察报告

页面目标：  
这是新用户的第一个 aha moment。

页面标题：

你的第一份一周观察报告

副标题：

基于过去 7 天的记录，Via 为你整理了一些温和的观察。

### 模块 1：本周主要产出

卡片标题：

这一周，你真正完成了什么

内容示例：

这一周你多次提到“完成方案”和“处理关键沟通”，说明你的主要产出集中在推进工作项目和解决实际问题上。

### 模块 2：常见时间消耗

卡片标题：

哪些事情消耗了你的时间

内容示例：

你有几天提到临时消息和无目的刷手机。它们不一定是问题，但可能在打断你本来想完成的事情。

### 模块 3：明天/未来目标倾向

卡片标题：

你最近最想靠近的方向

内容示例：

你多次写到想把方案推进完，也希望让生活更有秩序。Via 看到的是：你正在寻找更稳定的节奏。

### 模块 4：开心事件来源

卡片标题：

让你感到轻松的事情

内容示例：

本周让你开心的内容多和完成感、家人、安静时间有关。

### 模块 5：不开心事件来源

卡片标题：

让你感到消耗的事情

内容示例：

本周的不开心多来自拖延、沟通压力和时间被打断。

### 模块 6：AI 的 3 条建议

标题：

下周可以轻轻尝试的 3 件事

建议示例：

1. 每天先完成最重要的一件事，再处理零碎事务。
    
2. 把容易浪费时间的事情放到固定时间段，而不是随时发生。
    
3. 当一天不顺时，不急着否定整天，只把它当作一个信号。
    

底部按钮：

- 保存报告
    
- 回到首页
    
- 导出报告

#### 本周最重要的 3 个产出

- 完成了产品方案
    
- 解决了一次关键沟通
    
- 保持了几天稳定记录
    

#### 本周时间消耗点

你多次提到信息流、临时沟通和拖延启动。它们可能不是单独的问题，而是和精力状态有关。

#### 下周建议

1. 每天上午先处理一个最重要任务
    
2. 给临时消息设置固定处理时间
    
3. 每天晚上只写一句今天最值得保留的事
